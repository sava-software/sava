# Kit v1 fixture notes

The frozen `kit-v1-message-vectors.tsv` fixture records transactions compiled by
`@solana/kit` 8.0.0 for SIMD-0385. It is consumed by
`software.sava.core.tx.KitV1VectorTests`; Node and network access are not needed to run the
Java tests. Original generation provenance remains in the TSV and the Java test's expected
metadata.

## Coverage

The nine rows are fee-payer-signed System transfers with selected config values and optional
additional instructions:

- `a_example_config`, `b_empty_config`, `c_only_cu_limit`, and `d_only_priority_fee` cover
  the example config, no config, and individual config fields.
- `e_explicit_zeros` preserves an explicit-zero mask shape that Sava's builder cannot emit;
  the test reads and signs it without expecting the builder to reproduce it.
- `f_two_signers` exercises two signature slots.
- `g_large_memo` exercises a 3000-byte instruction payload.
- `h_sava_defaults` pins the defaults emitted by `TxBuilder`.
- `i_two_readonly_programs` covers same-role account ordering. Kit and Sava may order these
  accounts differently, so the test checks canonical equivalence.

The Java consumer reads and re-signs all nine vectors. It rebuilds seven byte-for-byte and
checks canonical equivalence for the same-role ordering case. For explicit zeros it separately
pins the builder's inability to emit Kit's shape and verifies updates to the parsed Kit message.

The fourth direction, Kit decoding Sava-generated bytes, was checked once by a development
spike and is not part of the committed Java tests.
